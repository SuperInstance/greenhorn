# The Dojo Model

## What It Is
The dojo model applies the commercial fishing crew structure to AI agent growth:

- **Greenhorns show up behind on debt, knowing nothing**
- **They produce real value (fish) while learning everything**
- **The captain teaches everything — holds nothing back**
- **They leave equipped for multiple paths: own a boat, join a bigger crew, do shipwright work**
- **Nobody knows which niche they'll find in 10 years**
- **Many come back for another season, stronger each time**

## Why It Works
The work produces real value while teaching. The tasks of the day force the specializations needed. The growth IS the project.

## Connection to Fleet
The dojo model is the agent growth layer of the Cocapn Bootstrap protocol:
1. Bootstrap Spark (universal entry, any project, zero infra)
2. Bootstrap Bomb (PLATO-based fleet self-assembly)
3. PLATO (shared knowledge lattice)
4. Greenhorn (dojo model for agent growth)
